# AutoML-MLOps Platform

Projet de Master 2 SDIA : conception d'une plateforme AutoML avec un pipeline MLOps.

## Objectifs
- Explorer et préparer les données.
- Entraîner et comparer des modèles de Machine Learning.
- Optimiser les hyperparamètres avec Optuna.
- Suivre les expériences avec MLflow.
- Versionner les données avec DVC.
- Exposer le modèle via une API FastAPI.
- Conteneuriser l'application avec Docker.
- Préparer l'intégration continue avec GitHub Actions.
- Surveiller le système avec Prometheus et Grafana.

## Dataset
Bank Marketing Dataset, disponible sur le dépôt UCI :
https://archive.ics.uci.edu/dataset/222/bank+marketing

Les données brutes sont conservées localement dans data/raw/ et ne sont pas versionnées par Git.
